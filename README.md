# 双人坦克大战游戏 (模块化版本)

这是一个基于HTML5 Canvas的双人坦克大战网页游戏，支持单人AI模式和双人对战模式。

## 🆕 新功能更新

### 🤖 AI对手系统
- **智能AI**: 实现了具有决策能力的AI对手
- **单人模式**: 按F1键切换单人模式，与AI对战
- **AI行为**: AI会主动寻找目标、移动和射击
- **难度适中**: AI具有合理的反应时间和射击间隔

### 🔧 模块化重构
- **代码分离**: 将庞大的game.js拆分为多个模块
- **更好维护**: 每个类都有独立的文件
- **性能优化**: 更好的代码组织和执行效率

### 🎮 修复的问题
- **炮塔方向**: 修复了坦克炮塔不随移动方向转动的问题
- **车体旋转**: 坦克车体现在会根据移动方向正确旋转
- **AI标识**: AI坦克有明显的"AI"标识

## 游戏特色

### 🎮 游戏玩法
- **双人对战**: 支持两名玩家同时游戏
- **实时战斗**: 玩家可以移动坦克并射击对方
- **生命系统**: 每个玩家有3条生命
- **计分系统**: 击中对手可获得分数

### 🎯 核心功能实现

#### 1. 模块化设计
- 代码重构为模块化架构，包含独立的类：
  - `TankGame`: 游戏主控制器
  - `Tank`: 坦克类
  - `Bullet`: 子弹类
  - `Obstacle`: 障碍物类
  - `Particle`: 粒子效果类
  - `ObjectPool`: 对象池类

#### 2. 性能优化
- **对象池技术**: 实现子弹和粒子的对象池，减少垃圾回收
- **缓存渲染**: 优化渲染循环，提升游戏性能
- **高效碰撞检测**: 使用矩形碰撞检测算法

#### 3. 控制优化
- **玩家1控制**: WASD移动 + 空格射击
- **玩家2控制**: 方向键移动 + Enter射击
- **防止页面滚动**: 阻止空格键和Enter键的默认页面行为

#### 4. 地图系统
- **智能地图生成**: 障碍物密度控制在5%
- **路径优化**: 避免阻塞玩家起始位置
- **随机布局**: 每次游戏都有不同的地图布局

#### 5. 边界处理
- **完善的边界检测**: 防止坦克移出游戏区域
- **子弹边界处理**: 子弹超出边界自动销毁

#### 6. 视觉效果
- **粒子特效**: 爆炸时产生粒子效果
- **现代化UI**: 使用CSS3实现炫酷的界面设计
- **响应式设计**: 支持不同屏幕尺寸

## 🕹️ 游戏控制

### 玩家1（绿色坦克）
- **W**: 向上移动
- **S**: 向下移动
- **A**: 向左移动
- **D**: 向右移动
- **空格**: 射击

### 玩家2（蓝色坦克）
- **↑**: 向上移动
- **↓**: 向下移动
- **←**: 向左移动
- **→**: 向右移动
- **Enter**: 射击

### 🎮 游戏模式控制
- **F1**: 切换单人/双人模式

## 🚀 如何运行

### 方式1: 使用启动器（推荐）
1. 双击 `启动游戏.bat` 文件
2. 启动器会自动检查文件完整性并打开游戏

### 方式2: 手动启动
1. 确保所有文件在同一目录下：
   - `index.html`
   - `game-main.js`
   - `tank.js`
   - `bullet.js`
   - `game-utils.js`
   - `styles.css`

2. 用现代浏览器打开 `index.html` 文件

3. 开始游戏！

## 📁 文件结构

```

```
